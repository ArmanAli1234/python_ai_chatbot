4. `print()` displays the result on the screen.

Each snippet is self‑contained and can be copied into a file or an interactive session and run as‑is.

## 1. Plain (regular) function  

```python
def add(a: int, b: int) -> int:
    """Return the sum of two integers."""
    return a + b

# Example usage
print(add(3, 5))          # → 8
```

*What makes it a “regular” function?*  
It’s defined with `def`, has a name, can be called anywhere, and returns a value with `return`.

---

## 2. Function with *args* and **kwargs  

```python
def concat(*parts: str, sep: str = " ", **options) -> str:
    """
    Join any number of strings together.
    *parts – positional arguments (any length)
    sep    – keyword‑only argument with a default
    **options – catches any extra named arguments (unused here)
    """
    return sep.join(parts)

print(concat("Python", "is", "awesome"))                # → Python is awesome
print(concat("a", "b", "c", sep="-", extra=42))         # → a-b-c  (extra is ignored)
```

*Why the asterisks?*  

* `*parts` collects an arbitrary number of positional arguments into a tuple.  
* `sep` is a **keyword‑only** argument because it appears after `*parts`.  
* `**options` gathers any extra named arguments into a dictionary.

---

## 3. Lambda (anonymous) function  

```python
square = lambda x: x * x          # same as: def square(x): return x * x

print(square(7))                  # → 49
```

A `lambda` creates a tiny function without a formal `def` statement.  
Use it for short, throw‑away callables (e.g., as a `key` argument to `sorted`).

---

## 4. Generator function  

```python
def fibonacci(limit: int):
    """Yield the Fibonacci sequence up to `limit` numbers."""
    a, b = 0, 1
    for _ in range(limit):
        yield a
        a, b = b, a + b

# Consuming the generator
for n in fibonacci(8):
    print(n, end=" ")          # → 0 1 1 2 3 5 8 13
print()
```

A function that contains `yield` returns a **generator object**.  
Each call to `next()` (or a `for` loop) produces the next value without building the whole sequence in memory.

---

## 5. Async function (coroutine)  

```python
import asyncio

async def fetch_data(delay: float) -> str:
    """Pretend to fetch data after `delay` seconds."""
    await asyncio.sleep(delay)          # non‑blocking pause
    return f"data after {delay}s"

# Running the coroutine
async def main():
    result = await fetch_data(1.5)
    print(result)

# Only needed when you run the file directly
if __name__ == "__main__":
    asyncio.run(main())                 # → data after 1.5s
```

`async def` creates a **coroutine** that can be awaited.  
It’s useful for I/O‑bound work (network calls, file reads, etc.) where you don’t want to block the whole program.

---

## 6. Method inside a class – instance, `@staticmethod`, `@classmethod`

```python
class Circle:
    pi = 3.14159                     # class attribute

    def __init__(self, radius: float):
        self.radius = radius         # instance attribute

    # 1️⃣ Instance method – receives the instance (`self`)
    def area(self) -> float:
        return self.pi * self.radius ** 2

    # 2️⃣ Static method – no automatic first argument
    @staticmethod
    def circumference(radius: float) -> float:
        return 2 * Circle.pi * radius

    # 3️⃣ Class method – receives the class (`cls`)
    @classmethod
    def from_diameter(cls, diameter: float):
        return cls(diameter / 2)

# Using the three kinds of methods
c = Circle(5)
print(c.area())                                 # → 78.53975
print(Circle.circumference(5))                  # → 31.4159
d = Circle.from_diameter(10)
print(d.radius)                                 # → 5.0
```

* **Instance method** (`self`) works on a particular object.  
* **Static method** (`@staticmethod`) is just a regular function that lives in the class namespace; it doesn’t get `self` or `cls`.  
* **Class method** (`@classmethod`) receives the class itself (`cls`) and is often used as an alternative constructor.

---

## 7. Built‑in function (for reference)

Python ships with many functions written in C, e.g.:

```python
print(len([1, 2, 3]))   # → 3
print(sorted({3, 1, 2}))  # → [1, 2, 3]
```

You don’t write these, but you can treat them exactly like any other callable.

## Quick cheat‑sheet of “function types” we covered

| Type | Syntax keyword(s) | Typical use |
|------|-------------------|-------------|
| Regular function | `def name(...):` | General purpose |
| Positional/keyword‑only, *args, **kwargs | `def f(*args, kw1, **kwargs):` | Flexible APIs |
| Lambda | `lambda args: expr` | Small, inline callables |
| Generator | `def f(...): … yield …` | Lazy iteration |
| Async coroutine | `async def f(...): … await …` | Non‑blocking I/O |
| Instance method | `def method(self, …):` inside a class | Operates on an object |
| Static method | `@staticmethod` + `def method(...):` | Utility function in class namespace |
| Class method | `@classmethod` + `def method(cls, …):` | Alternative constructors, class‑level logic |
| Built‑in | (implemented in C) | Core language utilities |

1. Load a CSV file (or create a sample DataFrame).

You can copy the whole script into a file called `pandas_analysis_demo.py` or run it cell‑by‑cell in a Jupyter notebook.

```python
# --------------------------------------------------------------
# pandas_analysis_demo.py
# --------------------------------------------------------------
# A minimal end‑to‑end data‑analysis example using pandas.
# --------------------------------------------------------------

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# --------------------------------------------------------------
# 1️⃣  Create (or load) a DataFrame
# --------------------------------------------------------------
# For demonstration we generate a synthetic dataset that mimics
# a simple e‑commerce order table.
np.random.seed(42)                     # reproducible random numbers

n_rows = 1_000
df = pd.DataFrame({
    "order_id":      np.arange(1, n_rows + 1),
    "customer_id":  np.random.randint(1, 200, size=n_rows),
    "order_date":   pd.to_datetime(
        np.random.choice(pd.date_range("2022-01-01", "2022-12-31"), size=n_rows)
    ),
    "category":     np.random.choice(["Electronics", "Clothing", "Home", "Books"], size=n_rows),
    "quantity":     np.random.poisson(lam=2, size=n_rows) + 1,   # at least 1 item
    "unit_price":   np.random.uniform(5, 200, size=n_rows).round(2),
    "discount":     np.random.choice([0, 0.05, 0.10, 0.15], size=n_rows, p=[0.6, 0.2, 0.15, 0.05]),
    "returned":     np.random.choice([0, 1], size=n_rows, p=[0.95, 0.05])
})

# Add a column that we will analyse later
df["total_price"] = df["quantity"] * df["unit_price"] * (1 - df["discount"])

# --------------------------------------------------------------
# 2️⃣  Quick inspection
# --------------------------------------------------------------
print("🔎 First 5 rows")
print(df.head(), "\n")

print("📐 Shape:", df.shape)
print("🔢 Columns & dtypes:")
print(df.dtypes, "\n")

print("📊 Summary statistics for numeric columns")
print(df.describe().round(2), "\n")

print("❓ Missing values per column")
print(df.isna().sum(), "\n")

# --------------------------------------------------------------
# 3️⃣  Basic cleaning / preprocessing
# --------------------------------------------------------------
# In this synthetic data there are no missing values, but in a real
# dataset you might do something like:
# df["order_date"] = pd.to_datetime(df["order_date"], errors="coerce")
# df = df.dropna(subset=["order_date"])

# Ensure categorical columns are of type 'category' (optional, saves memory)
cat_cols = ["category", "returned"]
for col in cat_cols:
    df[col] = df[col].astype("category")

# --------------------------------------------------------------
# 4️⃣  Exploratory analysis
# --------------------------------------------------------------

# 4a️⃣  Total revenue per month
df["order_month"] = df["order_date"].dt.to_period("M")
monthly_rev = df.groupby("order_month")["total_price"].sum().reset_index()
monthly_rev["order_month"] = monthly_rev["order_month"].astype(str)

print("💰 Monthly revenue")
print(monthly_rev.head(), "\n")

# 4b️⃣  Average order value (AOV) per category
aov_by_cat = (
    df.groupby("category")
    .agg(
        orders=("order_id", "nunique"),
        revenue=("total_price", "sum"),
        aov=("total_price", "mean")
    )
    .reset_index()
)
print("📈 AOV by category")
print(aov_by_cat.round(2), "\n")

# 4c️⃣  Correlation matrix for numeric fields
numeric_cols = ["quantity", "unit_price", "discount", "total_price"]
corr = df[numeric_cols].corr()
print("🔗 Correlation matrix")
print(corr.round(2), "\n")

# 4d️⃣  Return rate per category
return_rate = (
    df.groupby("category")["returned"]
    .mean()
    .reset_index()
    .rename(columns={"returned": "return_rate"})
)
print("↩️ Return rate by category")
print(return_rate.round(3), "\n")

# --------------------------------------------------------------
# 5️⃣  Visualisation (optional but handy)
# --------------------------------------------------------------
sns.set_style("whitegrid")
plt.figure(figsize=(10, 4))

# 5a️⃣  Monthly revenue line plot
plt.subplot(1, 2, 1)
sns.lineplot(data=monthly_rev, x="order_month", y="total_price", marker="o")
plt.title("Monthly Revenue")
plt.xticks(rotation=45)
plt.ylabel("Revenue ($)")

# 5b️⃣  AOV by category bar plot
plt.subplot(1, 2, 2)
sns.barplot(data=aov_by_cat, x="category", y="aov", palette="viridis")
plt.title("Average Order Value by Category")
plt.ylabel("AOV ($)")

plt.tight_layout()
plt.show()

# --------------------------------------------------------------
# 6️⃣  Save results (optional)
# --------------------------------------------------------------
monthly_rev.to_csv("monthly_revenue.csv", index=False)
aov_by_cat.to_csv("aov_by_category.csv", index=False)
return_rate.to_csv("return_rate_by_category.csv", index=False)

print("\n✅ Analysis complete – results saved to CSV files.")
```
